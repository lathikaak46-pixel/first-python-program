# SMART CAMPUS ENERGY SAVER

A smart system designed to reduce electricity wastage in classrooms by detecting when students are absent automatically switching off lights and fans.
## Authors

- [@LATHIKAA SHARAN K](https://www.github.com/lathikaasharank)


## Documentation

### How it works
The system uses sensors to detect whether students are present in a classroom.When the classroom is occupied the lights and fans remain switched on.When no one is detected for a certain period the system automatically switches them off.

Benefits

*Reduces unnecessary electricity

*Helps lower electricity costs

*Prevents energy wastage

*Supports a sustainable campus

*Easy to use and manage

## how to run 
1. open 'program.py'
2. run the python program
3. enter 'yes' if students are present
4. enter 'no' if the classroom is empty
5. the program will display the appropriate action.
